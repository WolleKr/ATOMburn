# External references and provenance

ATOMburn is an independent implementation. The projects below are cited as
technical, workflow, protocol, or usability references only. Their source code,
tests, assets, documentation, and binaries are not bundled with ATOMburn.

## Open-source reference projects

- [MeerK40t](https://github.com/meerk40t/meerk40t) — MIT; GRBL, raster, CAM,
  geometry, and test concepts.
- [LaserWeb4](https://github.com/LaserWeb/LaserWeb4) — AGPL-3.0; workflow,
  device UX, and GRBL behavior reference only.
- [LaserFlow](https://github.com/praegustator/laserflow) — MIT; architecture and
  transport reference.
- [Rayforge](https://github.com/barebaric/rayforge) — MIT; CAM and workflow
  reference.
- [GRBL](https://github.com/gnea/grbl) — firmware protocol reference.
- [Node SerialPort](https://github.com/serialport/node-serialport) — MIT;
  transport dependency family.

The exact production dependency licenses are maintained in

assets, trademarks, or documentation. Any future reuse must be reviewed before
