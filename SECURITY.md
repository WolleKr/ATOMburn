# Security policy

## Supported versions

Only the latest release on the `main` branch is currently supported.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the
repository owner through a private GitHub security advisory or another private
channel listed on the repository profile. Include the affected version, the
smallest reliable reproduction, impact, and any suggested mitigation.

Do not include machine credentials, camera passwords, private network details,
laser-job files, or personal data in a report.

## Scope

Reports involving arbitrary code execution, unsafe renderer-to-main privilege
crossing, credential disclosure, unintended network access, or unsafe machine
control are especially important. A software stop never replaces a physical
emergency stop.
